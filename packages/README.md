# packages层职责

`packages/`只容纳可复用、无独立部署入口的工程和领域能力。共享不等于越权：供应价、身份数据域、订单类型和传输环境仍必须由各自契约与服务端守卫控制。

后续保留的共享目录：

| 目录 | 职责 | 最早任务 |
|---|---|---|
| `db/` | Prisma schema、迁移和数据库访问基础 | M0-005 |
| `contracts/` | 确定性OpenAPI、生成类型和错误码 | M0-008 |
| `ui/` | Web通用表现组件，不承载权限判断 | M0-006 |
| `miniapp-kit/` | 原生小程序 `wx.request` 契约适配层 | M0-008 |
| `adapters/` | 外部服务可替换接口与测试桩 | M0-005及以后 |
| `config/` | 配置Schema、环境分层和脱敏规则 | M0-007 |
| `test-kit/` | 测试夹具、契约断言和失败测试模板 | M0-009 |

依赖规则：共享包不得反向依赖 `apps/*`；底层包不得通过跨包相对路径绕过工作区依赖声明。
