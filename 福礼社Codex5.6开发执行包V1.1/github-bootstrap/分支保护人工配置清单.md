# GitHub分支保护人工配置清单

以下设置需仓库管理员在GitHub中人工确认，本模板不会自动修改权限：

- 默认分支：`main`。
- 必须通过Pull Request；至少1名授权人工批准。
- 必需状态检查：CI工作流`verify`，且分支必须为最新策略由团队确认。
- 未解决review threads时禁止合并。
- 禁止force push和删除`main`。
- 限制直接push到`main`；管理员是否同样受规则约束由人工决定。
- 生产Environment设置授权审批人；生产Secrets只存在于GitHub/密钥系统。
- CODEOWNERS至少覆盖Prisma迁移、支付/福利卡、权限、配送状态机和CI。
- Actions权限最小化；第三方Action固定主版本并定期审查。
- Merge方式、线性历史、签名提交和Dependabot由团队书面决定。

推荐标签：`m0`至`m6`、`p0`、`human-gate`、`blocked-external`、`security`、`finance-transaction`、`logistics-state-machine`、`needs-evidence`。
