# M3-P075 企业宣传页面契约

状态：`IN_PROGRESS / CI_PASS / HUMAN_MERGE_PENDING`。本切片对应综合方案 §8、§19.5 与 P0-075，只补齐公开宣传页面的内容完整性、授权展示和下一步入口，不提前实现 M5 CMS。

## 目标与完成定义

- `/about`、`/capabilities`、`/cases`、`/cases/[slug]`、`/news`、`/news/[slug]`、`/contact` 均由服务端 HTML 提供完整正文。
- 关于页说明公司主体、平台定位、服务理念和公开信息原则；未取得公开授权的证照图片、资质编号、荣誉、历程、地址和备案信息必须保持安全空态。
- 能力页覆盖品类商品、供应商准入、商品/价格审核、库存协同、统一订单、个人/企业配送隔离、公司统一售后与供应商对账边界。
- 案例页只展示已授权客户案例；没有授权时显示真实空态，匿名能力场景必须明确不是客户案例或背书。
- 规则公告显示固定版本、ISO 日期格式的生效时间和适用对象；未知 slug 返回 404，不以静默覆盖模拟历史版本。
- 上述列表与详情页面均提供明确下一步入口；桌面和移动端无横向溢出。

## 字段、权限与数据范围

本切片沿用 `apps/portal-web/src/public-content.ts` 的只读白名单，不新增持久化字段：

| 内容 | 允许公开字段 | 默认拒绝字段 |
|---|---|---|
| 公司说明 | 批准展示名、公司全称、已确认服务方向 | 证照原件、证照编号、税号、银行账号、地址、未授权资质/荣誉 |
| 客户案例 | 已记录公开授权后的展示名、类型、摘要和授权日期 | 未授权客户名称、Logo、图片、交易额、销量、效果背书 |
| 匿名场景 | 标题、摘要、步骤、结果和非客户案例声明 | 客户身份、内部指标、供应商名单 |
| 规则公告 | slug、标题、类别、版本、生效日期、适用对象、正文 | 内部价格、毛利、精确库存、结算阈值 |
| 联系方式 | 公司全称、客服渠道类型、批准的脱敏展示值 | 完整手机号、个人信息、未授权办公地址和服务时间 |

- Actor 固定为 `PUBLIC`，无会话、tenant、owner 或客户端归属输入。
- 页面继续使用 `force-static` 与 `revalidate=300`；不得变成 `private`、`no-store` 或 `noindex`。
- 公开 HTML、metadata、JSON-LD 和页面制品不得包含 `supplyPrice`、`approvedSupplyPrice`、`supplyAmount`、`grossMargin`、供应商应付、精确库存或完整客服手机。

## 状态、错误与失败行为

- 本切片没有写状态、金额、库存、账本或审核状态机；重复读取天然无副作用。
- 未授权案例和资质默认不发布；未知案例/公告 slug 使用 Next.js `notFound()` 返回 404。
- Prisma 迁移：`NONE`；OpenAPI/DTO：`NONE`；新增业务错误码：`NONE`。
- `NEG-M3-P075-01`：缺必需内容、版本/生效日期或明确 CTA 时验收失败。
- `NEG-M3-P075-02`：未授权资质/客户、完整联系方式或内部价格字段出现在公开 HTML 时验收失败。
- `NEG-M3-P075-03`：未知 slug 未 404、公告版本语义被覆盖或静态公开缓存边界回退时验收失败。

## 非目标与外部边界

- 不实现 PortalContent、修订、草稿、预览、审核、发布、下线、媒体上传、按 slug ISR 失效或业务咨询表单；这些属于 M5。
- 不补写客户名称、Logo、交易指标、资质图片、地址、服务时间、备案号、真实域名或生产材料。
- 不进入 P0-076 福利卡/供应商服务页完整性、P0-077 企业真实认证、企业交易或 M4 配送。
- 客户案例/资质公开授权、staging、真实域名、device 与 production 均保持 `NOT_EXECUTED`。
