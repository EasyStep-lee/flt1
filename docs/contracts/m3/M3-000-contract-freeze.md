# M3-000 契约冻结

状态：`CONTRACT_FROZEN / NOT_IMPLEMENTED`。本文件只冻结可编码边界，不表示 M3 业务、页面、迁移或真实支付已完成。

## 固定不变量

- 个人与企业可跨供应商下单，但只向江苏福礼团供应链科技有限公司统一结账；系统按供应商拆履约子单。
- 福利卡入账只允许企业福利发放、公司活动赠送、实体卡或卡密兑换三类；永久不存在个人现金充值 API、路由、按钮、配置或占位枚举。
- 个人线上现金通道只允许微信；个人支持福利卡全额和福利卡加微信。企业支持公司微信支付或对公转账，企业不使用个人福利卡。
- 金额均为整数分。支付回调、主动查询、关单与退款以业务键幂等；未知结果先查询，退款累计不超过实付且按原支付结构退回。
- 跨供应商库存预扣为同一事务的全有或全无操作；确认、释放均幂等，不能超卖。
- 买家 DTO 永不返回供应价；归属字段从已验证会话派生，数据库实体不直接序列化。
- 原生小程序只经 `miniapp-kit` 的唯一 `wx.request` 适配器复用生成类型。
- 门户公开内容使用 SSG/ISR；登录、预览和交易区必须 `noindex` 且 `Cache-Control: private, no-store`。
- M3 只发布供 M4 消费的 outbox 契约，不创建 `DeliveryTask` 或 `EnterpriseDeliveryOrder`。
