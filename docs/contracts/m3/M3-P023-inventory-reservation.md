# M3-P023 跨供应商订单库存原子预扣契约

## 目标与边界

- 方案章节：§8 企业采购、§9 订单/福利卡/支付；P0-023。
- 个人或企业提交订单时，在创建 `BuyerOrder`、供应商履约子单和订单项的同一数据库事务中预扣全部共享 SKU 库存。
- 本切片只实现库存预扣及供后续取消、明确支付失败、支付超时调用的内部幂等释放契约；不创建福利卡、微信支付、退款、配送或结算能力。
- 支付结果为 `UNKNOWN` 或订单已支付时禁止释放；M3-P024 及后续保持锁定。

## 字段、状态与不变量

- 库存真源仍是每个 SKU 唯一的 `InventoryBalance`，不创建第二套库存余额。
- 预扣：`availableQty -= quantity`、`reservedQty += quantity`；释放反向执行；`availableQty + reservedQty + soldQty + damagedQty` 在两种操作前后守恒。
- 每次成功变更令 `version` 恰好增加 1，并追加 `InventoryChangeLog`；既有不可变触发器继续禁止修改或删除历史。
- 订单内 SKU 按 `skuId` 固定顺序更新，使用条件更新校验版本和非负可用量，降低并发死锁并防止超卖。
- 任一 SKU 缺少余额、库存不足或并发冲突时，订单、子单、订单项、库存余额、库存流水和库存命令全部回滚。
- 预扣命令与释放命令分别使用服务端生成的业务范围和幂等键写入 `InventoryCommand`；同请求重放不重复占用或释放。

## 权限、DTO 与错误码

- 买家只可通过既有 API-036/API-048 提交 `items[{skuId,quantity}]`；公司、买家、供应商、价格、库存版本及库存归属均由服务端派生。
- 对客响应白名单不新增库存余额、库存流水、供应价、供应商应付或内部幂等字段。
- 库存不足或缺少可成交库存返回 `409 INVENTORY_INSUFFICIENT`；并发事务冲突返回 `409 INVENTORY_RESERVATION_CONFLICT`；均不得产生部分写入。
- 内部释放仅接受 `USER_CANCELLED`、`PAYMENT_FAILED`、`PAYMENT_TIMEOUT`；未知支付结果或已支付状态返回状态冲突且不释放。

## 验收与失败测试

- 正常：跨至少三个供应商的订单一次提交后，全部 SKU 准确从可用量转入预留量并各写一条预扣流水。
- NEG-M3-P023-01：数量非法仍由请求白名单返回 `VALIDATION_FAILED`，不写订单或库存。
- NEG-M3-P023-02：未认证或错误归属仍在进入仓储前拒绝，不写订单或库存。
- NEG-M3-P023-03：库存不足、并发争用或同幂等键异请求返回冲突，整单不产生部分占用。
- 失败恢复：明确取消、支付失败或超时释放全部预扣；重复释放返回原结果；`UNKNOWN` 不释放。
- 环境边界：本切片使用本地数据库迁移演练、自动化测试和 CI；真实微信、staging、真机与 production 均不在本切片宣称通过。

## 回滚

- 应用回滚时回退订单仓储、错误映射、测试、契约和台账；已生成的订单库存流水保留为审计历史。
- 本切片复用既有表和枚举，不回改已发布迁移；如后续需要数据库修复，只能新增向前迁移。
