# M3-P073 门户全站导航契约

## 任务边界

- 阶段/任务：`M3 / M3-P073`；主验收：`P0-073`；页面映射：`PAGE-030`。
- 目标：桌面和移动端公开门户均可到达首页、关于、供应链能力、社区集采、福利卡、供应商合作、新闻和联系；企业公开态与私有交易态显示正确入口；页脚包含公司主体、脱敏客服手机和法律入口。
- 非目标：P0-074 首页内容闭环、P0-076 福利服务详情、P0-077 真实企业登录、P0-079 完整结算、P0-080 工作台订单、CMS、M4 配送和生产发布。

## 页面与状态契约

- 公开路由组继续使用 Next.js 静态生成/ISR。公开导航至少包含八个固定入口；既有“服务场景”入口可以保留，不改变固定入口含义。
- 未登录公开态显示“企业注册”和“企业登录”，不得显示私有采购车或企业工作台入口。
- 私有企业路由组显示“企业采购货架”“企业采购车”“企业工作台”，不复用公开态动作；所有交易响应保持 `noindex`、`Cache-Control: private, no-store` 和 `X-Robots-Tag: noindex`。
- 福利卡导航落到联系页的企业福利服务区，不新增个人现金充值入口或未来占位。
- 页脚展示经营主体 `江苏福礼团供应链科技有限公司`、对客脱敏手机 `189****9999`，并提供平台服务协议和隐私政策有效路由。

## 法律与外部边界

- 法律入口属于本切片；正式协议、隐私政策、版本号和生效日期不属于 Codex 可自行批准的内容。
- 法律页明确标记 `NOT_EXECUTED`，不得以占位页冒充已完成法务审定或生产发布。
- 真实域名、备案、staging 和 production 均保持 `NOT_EXECUTED`。

## 数据、API 与错误码

- 本切片无数据库模型、迁移、OpenAPI、DTO 或新错误码；复用现有公开内容和私有路由缓存边界。
- 不创建登录会话、企业权限或业务 API 假实现；P0-077 负责真实登录和认证闭环。
- 页面不读取或展示供应价、供应商应付、个人敏感信息或内部财务数据。

## 验收映射

- 正常路径：桌面和 390px 移动视口均可看到八个固定公开入口；企业公开动作、页脚主体/脱敏手机/法律入口均可访问。
- `NEG-M3-P073-01`：公开态不得出现采购车或工作台，法律入口不得伪装为正式法务文本。
- `NEG-M3-P073-02`：私有企业区域不得降级为公开缓存或可索引页面；公开区域不得泄露私有交易入口状态。
- `NEG-M3-P073-03`：重复导航与桌面/移动切换不产生状态副作用、横向溢出或错误业务入口。
- 行为测试：`tests/e2e/p0/p0-073-portal-navigation.spec.ts`；契约测试：`tests/contracts/m3-p073-portal-navigation.contract.test.mjs`。
