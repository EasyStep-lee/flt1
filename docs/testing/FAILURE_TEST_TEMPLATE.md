# 失败测试与RED→GREEN证据模板

每个任务或P0切片在实现前复制本模板。失败必须来自尚未实现的目标能力；依赖未安装、拼写错误、环境损坏或无关回归不能作为有效RED证据。

## 基本信息

- TaskID / P0ID：
- 不变量或验收条款：
- 影响层级：单元 / API契约 / 浏览器E2E / 真机 / 人工
- 测试文件与用例名：
- 执行环境（OS、Node、pnpm、数据库/浏览器）：

## RED（实现前）

- 执行命令：
- 起始提交：
- 退出码：
- 失败断言：
- 预期失败原因：
- 已排除的环境或既有回归：
- 原始输出/报告路径：

## GREEN（最小实现后）

- 执行命令：
- 实现提交：
- 退出码：
- 通过用例数：
- JUnit / JSON / HTML报告路径：
- 回归测试与结果：

## 必查风险

- 权限、数据域和敏感字段：
- 金额、状态机和失败回滚：
- 幂等：同一幂等键重复、并发重复、未知结果恢复：
- 并发：竞争参与者、期望赢家数、版本/锁策略、失败码：
- 日志、缓存、导出和错误响应泄露：

## 未覆盖与人工边界

- 未执行项及原因：
- 真机/预发布/生产人工事项：
- 不得据此声称通过的更高层门禁：
