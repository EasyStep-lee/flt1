## 实际变更

- `CategoryTemplate` 增加 `GENERIC|FOOD` profile 和前向迁移；既有模板回填 `GENERIC`，已发布 profile 与 JSON 定义共同不可覆盖。
- FOOD 模板固定配料、营养、生产许可、保质期、储存、过敏原六项商品字段，口味、净含量、包装数三项 SKU 维度，以及五个详情模块。
- 供应商创建、修改和提交食品时，服务端按精确已发布版本验证必填纯文本、字段白名单和 SKU；禁止供应商替换、隐藏或注入固定食品提示。
- 新增公开 `GET /v1/catalog/products/{productId}`；只返回在售零售 SKU、整数分零售价、食品白名单字段、固定提示及公司统一销售/结账主体，不返回供应价、资质私有引用或内部快照。
- 公司商品运营页增加正式食品模板草稿预置；用户原生小程序增加商品详情页和 loading/error/retry 状态，唯一网络入口仍为 `miniapp-kit`。
- OpenAPI、共享类型和小程序契约确定性生成；P013 仅细化既有 API-030 的食品子集，P0-021/P0-088 保持未完成。

- 模板管理仍固定为公司 `COMPANY_PRODUCT_OPS` 页面和会话；供应商只按本方商品写入模板允许字段。
- profile 和模板内容在发布后不可修改；历史商品继续引用原 `categoryId + templateVersion`，后续版本不改写旧快照。
